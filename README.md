# AuraText 交互原型与排版规范

> 写作工具的三套静态页面原型：展示、注册、管理，双击即开。

## 它解决什么

在写第一行业务代码之前，先让人看见产品长什么样。这个仓库是 AuraText 写作工具的**视觉原型**：三套页面（展示、注册、管理）都做成可直接打开的单文件，改文案不用等构建。

## 说明

- 纯静态，无后端，交互为前端模拟
- 排版遵循中英文混排规范：中文用系统黑体、英文与数字用无衬线，行距与段距单独标定
- 配套的使用说明书为 Word 文档，未纳入仓库

## 技术栈

- **形态**：纯静态 HTML / CSS（含内联样式与图标资源）
- **内容**：产品展示页、注册交互原型、管理面板原型
